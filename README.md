# social-media-bilder

Technisches Hilfs-Repository für die automatische Facebook/Instagram-
Veröffentlichung von [webdesign-ehmann](https://github.com/Hannes0777/webdesign-ehmann).

**Keine Homepage, keine sichtbaren Inhalte.** Bilder landen hier nur für
wenige Sekunden, weil Instagrams Programmierschnittstelle zwingend eine
öffentlich erreichbare Bild-URL verlangt (kein direkter Datei-Upload
möglich). Der Workflow in webdesign-ehmann lädt ein Bild hoch, Instagram
holt es ab, danach wird es hier automatisch wieder gelöscht.
